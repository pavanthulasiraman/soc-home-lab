# Mini SOC Home Lab

A hands-on learning project focused on security monitoring
and incident investigation using Wazuh and Microsoft Sysmon.

## Project status

Work in progress — planning the lab environment.
No detections or investigations have been completed yet.

## Goals

- Build an isolated lab with Wazuh and a Windows test endpoint.
- Collect and investigate security events.
- Test detections using suspicious and normal activity.
- Document evidence, alternative explanations, and recommended responses.

## Planned documentation

This repository will include setup instructions, an architecture
diagram, detection configurations, sanitized sample logs,
investigation reports, and supporting screenshots.
